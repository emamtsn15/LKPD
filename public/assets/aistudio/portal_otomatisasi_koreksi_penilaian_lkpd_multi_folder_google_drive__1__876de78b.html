Panduan Deploy Google Apps Script (Web App + Trigger Harian + Embed Google Sites)

1

Buat Proyek Apps Script

Buka script.google.com → Proyek Baru → tempel kode Code.gs di bawah, lalu isi GEMINI_API_KEY Anda.

2

Aktifkan Trigger Harian

Pilih fungsi pasangTriggerHarian lalu klik Jalankan (Run) satu kali untuk menjadwalkan koreksi ulang otomatis setiap hari.

3

Deploy sebagai Web App

Klik Terapkan → Deployment Baru → Aplikasi Web. Atur Jalankan sebagai: Saya dan Yang memiliki akses: Siapa saja.

4

Sematkan ke Google Sites

Salin URL Web App (.../exec), lalu di Google Sites pilih Sisipkan (Embed) → Berdasarkan URL.
